# 重绘局部回填与过程产物下载 - 实施计划

## 1. Summary
按照 plan.md 的要求：
1. 修改 `applyAiRepair` 的回填策略：不替换整张图，而是保持原图层尺寸、裁剪和位置不变，仅将重绘结果按原遮罩区域合成回原图层
2. 在"导出成品"弹窗底部左侧新增"过程产物"按钮和下拉列表，汇总当前文档所有图层的 AI 产物

## 3. Proposed Changes

### 3.1 新增局部回填辅助函数 (imageEditBridge.ts)

**新增函数 `compositeRepairResult`：**
```typescript
export async function compositeRepairResult(
  originalSource: string,      // 原图 source
  repairedSource: string,      // 重绘结果图
  maskDataUrl: string,         // 遮罩图 (from renderRepairMaskDataUrl)
  cropWidth: number,           // 当前 crop.width
  cropHeight: number           // 当前 crop.height
): Promise<string>             // 合成后的 data URL
```

**实现逻辑：**
1. 加载原图和重绘结果图
2. 如果重绘结果尺寸与 crop 区域不一致，按 crop 尺寸缩放
3. 创建 canvas，大小为 cropWidth x cropHeight
4. 绘制原图 crop 区域
5. 使用 "destination-in" 合成模式，先绘制重绘结果（保留原图被遮罩区域）
6. 替代方案：绘制原图后，用重绘结果和遮罩做 "source-over" 合成，仅遮罩白色区域覆盖

**实际采用方案（基于现有 mask 逻辑）：**
1. 创建 canvas (cropWidth x cropHeight)
2. 绘制原图 crop 区域
3. 缩放重绘结果到 crop 尺寸
4. 使用 `drawImage` 将重绘结果覆盖到 canvas
5. 注意：这里需要用 mask 来控制哪些像素被替换

更精确的实现：
1. 加载原图 crop 区域绘制到 canvas
2. 加载重绘结果并缩放到 crop 尺寸
3. 加载 mask
4. 创建临时 canvas 绘制"仅遮罩区域的重绘结果"
5. 使用 `getImageData` + `putImageData` 或 `globalCompositeOperation` 实现遮罩合成

**新增 state 和计算逻辑：**
```typescript
const [isProcessProductsOpen, setIsProcessProductsOpen] = useState(false);

const processProducts = useMemo(() => {
  const products: Array<{
    type: "重绘结果" | "3D 模型";
    layerLabel: string;
    downloadUrl: string;
    fileName: string;
  }> = [];

  document.layers.forEach((layer, index) => {
    if (layer.type !== "image") return;

    // 重绘产物
    if (layer.aiMeta.repairTask?.status === "succeeded" && layer.aiMeta.repairTask.downloadUrl) {
      products.push({
        type: "重绘结果",
        layerLabel: layer.name || `图层 ${index + 1}`,
        downloadUrl: layer.aiMeta.repairTask.downloadUrl,
        fileName: layer.aiMeta.repairTask.fileName || "repair-result.jpg"
      });
    }

    // 3D 产物
    if (layer.aiMeta.model3dTask?.status === "succeeded" && layer.aiMeta.model3dTask.downloadUrl) {
      products.push({
        type: "3D 模型",
        layerLabel: layer.name || `图层 ${index + 1}`,
        downloadUrl: layer.aiMeta.model3dTask.downloadUrl,
        fileName: layer.aiMeta.model3dTask.fileName || "model.glb"
      });
    }
  });

  return products.reverse(); // 逆序展示
}, [document.layers]);
```

## 6. Assumptions & Decisions

1. **返回图尺寸策略**：假设 AI 接口返回的是针对当前 crop 区域的完整新图，因此需要按 crop 尺寸缩放后合成
2. **遮罩合成方式**：使用白色区域标识需要替换的像素，黑色区域保持原图
3. **下载 URL 方案**：继续使用 `toCanvasSafeImageUrl` 转换后的代理 URL，仅用于工作台可读
4. **产物汇总顺序**：按图层遍历逆序展示（最新的在前面），无时间戳则按稳定顺序

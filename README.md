# Web 修图工作台

面向抖音电商 AIGC 带货图文生成后的二次精修工具。它不是专业设计软件，而是一个电商场景下的轻量化修图工作台，强调上手快、改得准、出图快，帮助商家、达人和运营把“不满意的 AI 初稿”快速修到“可发布、可投放、可转化”。

## 项目定位

- `用户价值`
  - 不用重新生成，也不用跳转第三方工具，就能快速把 AI 图修到可发布、可投放、可转化。
- `平台价值`
  - 提升生成素材可用率，降低二次生成成本，增强内容生产粘性，并沉淀电商视觉编辑能力。
- `当前技术定位`
  - 基于 `React + TypeScript + Vite + Fabric.js` 的桌面端 Web 编辑工作台，按仓库内的 `Spec-Driven Development` 体系持续迭代。

## 功能全景

完整产品视角下，Web 端修图覆盖以下能力方向：

- 基础画布能力：图片加载、画布缩放、拖拽移动、撤销重做、历史记录、快捷键
- 涂抹与局部调整：笔刷、橡皮擦、蒙版、局部重绘、局部调整
- 花字与营销文字：添加文字、花字模板、描边阴影、渐变背景条、文案建议
- 滤镜与调色：基础调节、电商滤镜、一键增强、风格预设、前后对比
- 比例调整与裁剪：自由裁剪、固定比例、平台模板、智能扩图、安全区提示
- 图层管理：排序、显示隐藏、锁定、复制删除、透明度
- 素材与贴纸：贴纸、价格标签、装饰元素、品类素材、搜索与收藏
- 导出与发布衔接：导出图片、清晰度选择、草稿、版本管理、回填到图文流程、合规检测

详细说明见 [产品愿景](./docs/product/vision.md)、[路线图](./docs/product/roadmap.md) 和 [MVP 审计](./docs/product/mvp-audit.md)。

## 推荐 MVP 完成度检查

下面这张表按“推荐 MVP 必做功能”检查当前仓库实现，而不是按远期产品全量能力检查。

| 模块 | 推荐 MVP 必做 | 当前状态 |
| --- | --- | --- |
| 画布 | 图片加载、缩放、拖拽、撤销重做 | `已完成`：图片加载、缩放、手型平移、撤销重做已完成 |
| 涂抹 | 笔刷、橡皮擦、局部重绘 | `未完成` |
| 文字 | 添加文字、基础花字模板、描边阴影 | `已完成`：添加文字、四类高频花字模板、描边、阴影、渐变、背景条已完成 |
| 滤镜 | 基础调节、电商滤镜、一键增强 | `已完成`：基础调节、电商滤镜预设、一键增强已完成 |
| 比例 | 裁剪、固定比例、智能扩图 | `部分完成`：固定比例、安全区、自由裁剪与快捷裁剪已完成；智能扩图未完成 |
| 图层 | 图层排序、隐藏、删除、锁定 | `已完成` |
| 导出 | 保存草稿、导出图片、回填到图文流程 | `部分完成`：草稿恢复、PNG/JPEG 导出已完成；回填到图文流程未完成 |

结论：`推荐 MVP 必做功能尚未全部完成`。当前仓库已经具备“轻量电商精修工作台”的主骨架，但距离推荐 MVP 仍有几块关键缺口，优先级最高的是：

1. 涂抹 / 橡皮擦 / 局部重绘
2. 智能扩图
3. 回填到图文流程
4. 前后对比和主体保护
5. 素材与贴纸体系

## 当前已实现

- 画布比例切换：支持 `1:1 / 3:4 / 4:5 / 9:16 / custom`
- 安全区展示：画布内显示安全区边界
- 图片导入：支持本地图片导入并生成图片图层
- 画布对象编辑：选中、拖拽、缩放、旋转结果会回写到 store
- 视口平移与缩放：支持手型平移和基于文档模型持久化的视口缩放
- 图层管理：支持图层选中、重命名、显示隐藏、锁定、复制、删除、上下移动
- 花字编辑：支持新增文字层、编辑文案、字号、字重、描边、阴影、渐变、背景条和高频花字模板
- 基础滤镜：支持亮度、对比度、饱和度、模糊、锐化、色温、电商滤镜预设和一键增强
- 裁剪适配：支持自由裁剪和 `1:1 / 4:5 / 9:16` 快捷裁剪
- 撤销重做：支持按钮和快捷键 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Y` / `Cmd+Shift+Z`
- 草稿恢复：支持自动保存到本地并在刷新后恢复
- 导出：支持 `PNG / JPEG`，可调整质量与倍率，并自动带比例/版本号命名

## 当前未完成或仅部分完成

- 智能扩图、前后对比、主体保护

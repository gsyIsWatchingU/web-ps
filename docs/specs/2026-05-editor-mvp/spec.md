# Editor MVP Spec

## 元信息

- Status: active
- Owner: frontend
- Last Updated: 2026-05-16
- Related Roadmap: `MVP`

## 背景与问题

AIGC 生成的带货图文可以快速给出初稿，但在商品主图清晰度、文字包装、尺寸适配和投放风格上往往不能直接使用。团队需要一个桌面端 Web 工作台，承接 AI 初稿后的二次精修，避免频繁切换到更重的设计工具。

## 目标用户与核心场景

- 目标用户：电商运营、设计支持、投放人员
- 核心场景：导入 AIGC 初稿图，在浏览器内完成比例调整、花字包装、图层整理、滤镜微调、撤销恢复和导出

> 说明：本 spec 对应的是当前代码仓库内较收敛的一版 MVP，不包含推荐产品形态中的涂抹、局部重绘、智能扩图和图文流程回填。这些能力会在后续版本另起 spec 继续迭代。

## 用户故事

- 作为电商运营，我希望快速切换常用电商比例并调整画面布局，以便适配不同渠道投放。
- 作为设计支持，我希望在浏览器内直接编辑标题、价格标签和卖点花字，以便快速产出高可用海报。
- 作为投放人员，我希望导出清晰稳定的最终素材，并在误操作后能撤销或恢复草稿。

## 成功标准

- 用户可以在单个工作台中完成导入、编辑、恢复和导出主链路。
- 10 到 20 个图层下的常用编辑交互保持稳定。
- 历史栈、草稿恢复和导出结果一致性可接受。

## 功能范围

- In Scope:
  - 画布比例切换与安全区
  - 图片导入与基础变换
  - 图片层、文字层、装饰层管理
  - 花字样式系统
  - 基础滤镜
  - 撤销重做
  - 本地草稿恢复
  - PNG/JPEG 导出
- Out of Scope:
  - AI 局部重绘、智能消除、扩图
  - 多人实时协同
  - PSD 兼容和高级像素级编辑

## 关键交互说明

1. 用户进入编辑器后选择目标画布比例，系统展示对应安全区。
2. 用户导入一张或多张图片，系统自动生成图片图层。
3. 用户可新增文字层和装饰层，并在右侧面板修改样式。
4. 用户可以在图层面板中进行显示隐藏、锁定、重命名、排序和复制删除。
5. 用户对图片层应用基础滤镜，对文字层应用描边、阴影、渐变、背景条等花字样式。
6. 用户可使用撤销/重做恢复编辑过程，也可在刷新后从本地草稿恢复。
7. 用户完成编辑后按目标格式导出最终素材。

## 验收标准

- AC-1: 用户可在 `1:1 / 3:4 / 4:5 / 9:16 / 自定义` 比例间切换，已有图层状态保持可预期。
- AC-2: 用户可导入图片并完成缩放、旋转、翻转、裁切等基础操作。
- AC-3: 用户可创建、编辑和删除 `image / text / decoration` 三类图层，并在面板中调整层级。
- AC-4: 文字层支持至少 `描边 / 阴影 / 渐变 / 背景条` 四种花字能力。
- AC-5: 图片层支持至少 `亮度 / 对比度 / 饱和度 / 模糊 / 锐化 / 色温` 六类基础滤镜。
- AC-6: 用户连续执行至少 20 次操作后，撤销/重做结果与视觉状态一致。
- AC-7: 浏览器刷新后可恢复最近一次本地草稿。
- AC-8: 用户可导出 PNG/JPEG，且导出尺寸与配置一致。

## 当前实现状态

- 已完成：
  - `AC-1` 比例切换与安全区
  - `AC-3` 三类图层创建与基础管理
  - `AC-4` 描边 / 阴影 / 渐变 / 背景条
  - `AC-5` 亮度 / 对比度 / 饱和度 / 模糊 / 锐化 / 色温
- 基本完成但仍需补验收或增强：
  - `AC-6` 撤销 / 重做功能已落地，但尚缺“20 次连续操作”的正式自测记录
  - `AC-7` 草稿恢复已落地，但尚缺异常与边界场景自测记录
  - `AC-8` PNG/JPEG 导出已落地，但尚缺导出一致性专项校验
- 未完成：
  - `AC-2` 中的“裁切”等真实交互仍未落地，目前只有扩展位

## 非功能要求

- 性能：10 到 20 个图层下的拖拽、选中、排序和样式修改不出现明显卡死。
- 稳定性：导入异常图片、滤镜参数越界和草稿恢复失败时有兜底处理。
- 可恢复性：核心编辑状态可持久化到本地草稿。

## 未决问题

- 裁切交互是首版内置到图片层能力中，还是延后到后续迭代增强。
- 花字预设样式是否在 MVP 内提供默认模板集。
- 自定义比例是否允许保存为常用预设。

# 编辑器领域模型

## 目的

本文件用于统一项目中的核心术语，避免在设计、代码和沟通中混用“图层、对象、元素、组件”等概念。除非上下文特别说明，后续文档优先采用本文件的命名。

## 核心概念

### EditorDocument

用户一次编辑会话的完整状态集合，是保存、恢复、导出和历史追踪的最小单元。

建议包含：

- `canvas`
- `layers`
- `selection`
- `historyMeta`
- `exportConfig`
- `draftMeta`

### Canvas

画布是承载所有可编辑内容的空间定义，不等同于浏览器中的实际 DOM 容器。

建议属性：

- 宽高
- 比例
- 背景色或背景图
- 安全区
- 缩放级别
- 平移状态

### Layer

图层是用户可感知、可排序、可隐藏、可锁定的编辑单元。图层是领域模型中的一级对象，不直接暴露底层渲染库对象作为业务模型。

统一属性：

- `id`
- `type`
- `name`
- `visible`
- `locked`
- `opacity`
- `transform`
- `zIndex`

### LayerType

首版固定三类图层：

- `image`
  - 商品图、背景图、AI 初稿图等位图内容。
- `text`
  - 标题、副标题、价格标签、卖点文案等。
- `decoration`
  - 贴纸、色块、边框、标签条、辅助装饰元素。

### Selection

当前被用户选中的一个或多个图层集合。Selection 是编辑器交互态的一部分，不应直接与业务保存状态耦合。

### History

历史栈记录用户意图级别的操作，而不是底层渲染对象的所有瞬时变化。后续所有撤销/重做行为都以命令级变更为基本单位。

### ExportConfig

导出行为配置，包括：

- 文件格式
- 画质
- 导出倍率
- 背景透明策略

### Draft

本地草稿是 EditorDocument 的持久化快照，用于刷新恢复和异常恢复。草稿恢复是产品能力，不只是浏览器缓存行为。

## 关键关系

- 一个 `EditorDocument` 只对应一个 `Canvas`。
- 一个 `Canvas` 包含多个 `Layer`。
- 一个 `Layer` 在同一时刻只属于一个 `EditorDocument`。
- `Selection` 只引用当前文档中的图层。
- `History` 操作应能映射到 `Layer` 或 `Canvas` 的变化。

## 命名约束

- 用 `图层` 指代可排序、可隐藏、可锁定的业务对象。
- 用 `对象` 指代底层渲染库中的具体实例，例如 Fabric object。
- 用 `元素` 仅在描述 UI 或视觉构成时使用，不作为核心模型命名。
- 用 `组件` 指代 React 视图层单元。

## 后续扩展点

- 当需要支持图层分组时，可引入 `group` 作为特殊 LayerType。
- 当需要支持局部精修时，可补充 `mask` 或 `region` 相关模型。
- 当需要支持异步 AI 任务时，可在文档级增加 `jobMeta`。

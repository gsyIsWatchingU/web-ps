# Feature List

项目功能状态总表。状态统一使用：`已完成 / 开发中 / 待开始 / 暂缓`。

## 画布与视口

| 功能名 | 状态 | 简述 | 备注 |
| --- | --- | --- | --- |
| 画布缩放 | 已完成 | 支持预览缩放与视口状态持久化 | 已进入文档模型 |
| 画布平移 | 已完成 | 支持手型模式拖拽画布 | 视口约束已做一轮修正 |
| 比例切换 | 已完成 | 支持常见投放比例切换 | 当前覆盖 `1:1 / 3:4 / 4:5 / 9:16 / 自定义` |
| 安全区查看 | 已完成 | 在 UI 中展示平台安全区 | 仍建议继续做导出前校验 |
| 自由裁剪与快捷裁剪 | 已完成 | 支持自由裁剪和常用快捷比例 | 已接入主链路 |
| 智能扩图 | 待开始 | 通过 AI 补全裁剪外区域 | 推荐 MVP 缺口之一 |

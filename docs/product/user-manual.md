# Web 修图工作台使用手册

## 适用对象

本手册面向商家、运营、投放人员等业务同学，帮助你快速上手 Web 修图工作台，把 AIGC 生成的带货图修成可发布、可投放的电商素材。

## 产品能做什么

当前版本支持以下核心能力：

- 画布平移与缩放
- 比例切换与安全区查看
- 图片导入
- 自由裁剪和快捷裁剪
- 花字模板与文字样式编辑
- 电商滤镜预设与一键增强
- 图层管理
- 草稿自动恢复
- PNG / JPEG 导出

当前版本暂不支持：

- 涂抹、橡皮擦、局部重绘
- 智能扩图
- 图文流程回填

## 页面布局说明

进入网站后，可以把页面理解成 4 个区域：

- 左侧：任务入口和图层列表
- 中间：画布工作区
- 右侧：属性面板、导出设置、比例与视口控制
- 顶部工具栏：撤销、重做、添加图片层、添加花字层、导出

## 任务入口按钮说明

### 1. 选择

作用：选中画布中的图层，并在右侧属性面板中继续编辑。

适合做的事：

- 选中图片层、文字层、装饰层
- 调整缩放、旋转、透明度
- 修改图层名字
- 配合图层列表做排序、隐藏、锁定

### 2. 平移

作用：切到手型模式，拖动画布视口。

适合做的事：

- 放大后查看局部细节
- 在大画布中快速移动视角
- 不改变素材内容，只改变当前查看位置

### 3. 裁剪

作用：把图片裁到更适合投放的位置和比例。

适合做的事：

- 做自由裁剪
- 快速切换到 `1:1`、`4:5`、`9:16`
- 调整主体位置，避免标题或卖点超出安全区

说明：当前版本里，点击 `裁剪` 后，主要结合右侧图片属性区域完成裁剪操作。

### 4. 花字

作用：处理营销文案和花字包装。

适合做的事：

- 新增文字层
- 套用高频花字模板
- 修改卖点文案
- 调整字号、字重、颜色、描边、阴影、渐变、背景条

### 5. 滤镜

作用：统一商品图整体质感，让图片更适合电商投放。

适合做的事：

- 套用电商滤镜预设
- 使用一键增强
- 微调亮度、对比度、饱和度、锐化、色温

### 6. 装饰

作用：补充视觉标签，强化活动感和卖点表达。

适合做的事：

- 添加高亮条
- 添加角标
- 添加飘带
- 配合花字做促销信息包装

## 标准使用流程

建议按下面顺序使用：

### 第一步：导入图片

点击左侧或顶部的 `导入图片 / 添加图片层`，上传 AIGC 商品图或海报初稿。

### 第二步：选择投放比例

在右侧 `比例与视口` 中选择需要的投放比例，例如：

- `1:1`：商品主图
- `4:5`：信息流投放
- `9:16`：竖版封面

### 第三步：调整构图

如果主体不够居中或画面不适合投放：

- 切到 `平移` 查看局部
- 选中图片层，在右侧使用 `裁剪适配投放`
- 配合安全区检查标题和卖点位置

### 第四步：强化营销表达

如果卖点不够突出：

- 新增花字层
- 套用模板：
  - 主标题花字
  - 价格角标
  - 优惠券标签
  - 卖点高亮条

### 第五步：统一图片质感

如果图片发灰、层次不够或不够有带货感：

- 先试 `电商滤镜预设`
- 再试 `一键增强`
- 最后按需微调亮度、对比度、饱和度、锐化、色温

### 第六步：补充装饰信息

如果还需要活动感或标签感：

- 新增装饰层
- 选择 `高亮条 / 角标 / 飘带`
- 调整颜色，让它和商品图、花字风格保持统一

### 第七步：导出成品

确认无误后，在右侧 `导出与流程` 中设置：

- 导出格式：`PNG / JPEG`
- 导出倍率
- 导出质量

然后点击顶部 `导出投放成品`。

导出文件名会自动带上比例和版本号，方便后续管理。

## 各区域详细用法

### 图层列表

图层列表用于管理当前素材中的所有内容层。

支持操作：

- 查看图层
- 选中图层
- 显示 / 隐藏
- 锁定 / 解锁
- 上移 / 下移

选中图层后，还可以在右侧属性面板中继续修改名称、透明度、位置和样式。

### 属性面板

不同图层，右侧可编辑内容不同：

- 图片层
  - 裁剪
  - 滤镜
  - 一键增强
- 文字层
  - 内容
  - 字号
  - 字重
  - 颜色
  - 描边
  - 阴影
  - 渐变
- 装饰层
  - 形态
  - 颜色

### 导出与流程

这一块主要负责最终出图。

支持内容：

- `PNG / JPEG`
- 导出倍率
- 导出质量
- 最近导出文件名查看

## 常见使用场景

### 商品主图不够聚焦

先裁剪，再轻微锐化和提亮。

### 卖点不突出

新增花字层，套用高频模板，再补高亮条或角标。

### 需要适配不同投放位

切换 `1:1`、`4:5`、`9:16`，逐个检查安全区和标题位置。

### 图片整体发灰

先用电商滤镜预设，再少量微调对比度和饱和度。

### 误操作了

直接使用 `撤销 / 重做` 恢复。

### 页面刷新了

系统会自动恢复最近草稿。

## 使用建议

- 先定比例，再裁剪，再加花字，最后调滤镜，效率最高。
- 花字不要一次加太多，优先保证主标题和核心卖点清楚。
- 滤镜建议先用预设，再做少量微调，避免画面过重。
- 导出前务必检查安全区，确保标题、价格和卖点没有贴边或被裁掉。

## 当前版本边界说明

为了保证上手快和出图快，当前版本定位是“轻量电商精修工作台”，不是专业级设计软件。

因此你可以把它理解为：

- 适合快速补救 AI 初稿
- 适合生成投放素材
- 不适合做复杂像素级精修

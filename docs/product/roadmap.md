## MVP

目标：建立一个可用的桌面端 Web 电商精修工作台，让用户可以对 AIGC 带货图做轻量补救并导出结果。

### 推荐 MVP 必做

| 模块 | 功能 | 当前实现状态 |
| --- | --- | --- |
| 画布 | 图片加载、缩放、拖拽、撤销重做 | `部分完成` |
| 涂抹 | 笔刷、橡皮擦、局部重绘 | `未完成` |
| 文字 | 添加文字、基础花字模板、描边阴影 | `部分完成` |
| 滤镜 | 基础调节、电商滤镜、一键增强 | `部分完成` |
| 比例 | 裁剪、固定比例、智能扩图 | `部分完成` |
| 图层 | 图层排序、隐藏、删除、锁定 | `已完成` |
| 导出 | 保存草稿、导出图片、回填到图文流程 | `部分完成` |

### 当前代码仓库中的 MVP 范围

当前仓库不是“推荐 MVP 全量实现”，而是“推荐 MVP 的一版可运行骨架 + 部分主链路补齐”。如果按代码仓库当前边界定义 MVP，则核心落点是：

- 画布比例切换与安全区
- 图片导入与基础变换
- 图片层、文字层、装饰层管理
- 基础花字样式
- 基础滤镜
- 撤销重做
- 本地草稿恢复
- PNG/JPEG 导出

### MVP 下一步优先补齐顺序

1. 画布拖拽平移
2. 自由裁剪
3. 涂抹 / 橡皮擦 / 局部重绘
4. 电商滤镜模板与一键增强
5. 基础花字模板
6. 回填到图文流程

## v1.1

目标：提升运营效率和模板复用能力。

候选能力：

- 模板样式库
- 多尺寸导出配置
- 对齐辅助和吸附增强
- 图层分组
- 常用素材面板
- 电商贴纸和价格标签

进入条件：

- MVP 主链路稳定
- 图层和文档模型已沉淀完成
- 导出链路与历史栈行为明确

## v1.2

目标：为 AI 精修和更复杂工作流预留升级能力。

候选能力：

- AI 局部精修接口接入
- 蒙版或局部区域数据结构
- 智能扩图
- 一键增强
- 批量任务和异步处理
- 操作埋点和效果分析

进入条件：

- 推荐 MVP 必做能力至少完成一轮可追踪验收
- 规格、设计和任务文档流程已跑通至少一个完整迭代
- 关键技术决策已有 ADR 沉淀

## 维护规则

- 每个版本开始前先更新本文件，明确本次迭代目标和非目标。
- 如路线调整涉及长期方向变化，需要同步更新 `vision.md`。
- 如版本推进依赖关键技术策略变化，需要新增或更新 ADR。

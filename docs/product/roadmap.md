# Web 修图项目路线图

## 目标节奏

路线图按 `MVP / v1.1 / v1.2` 维护，优先保证首版编辑主链路稳定，再逐步补齐效率能力和 AI 能力。

## MVP

目标：建立可用的桌面端 Web 精修工作台。

包含能力：

- 画布比例切换与安全区
- 图片导入、缩放、旋转、翻转、裁切
- 图片层、文字层、装饰层的图层管理
- 花字样式系统：描边、阴影、渐变、背景条
- 基础滤镜：亮度、对比度、饱和度、模糊、锐化、色温
- 撤销重做
- 本地草稿恢复
- PNG/JPEG 导出

验收关注点：

- 10 到 20 个图层下保持稳定交互
- 常用电商比例可直接切换
- 导出清晰度和历史状态一致性可接受

## v1.1

目标：提升运营效率和模板复用能力。

候选能力：

- 模板样式库
- 多尺寸导出配置
- 对齐辅助和吸附增强
- 图层分组
- 常用素材面板

进入条件：

- MVP 主链路稳定
- 图层和文档模型已沉淀完成
- 导出链路与历史栈行为明确

## v1.2

目标：为 AI 精修和更复杂工作流预留升级能力。

候选能力：

- AI 局部精修接口接入
- 蒙版或局部区域数据结构
- 批量任务和异步处理
- 操作埋点和效果分析

进入条件：

- 规格、设计和任务文档流程已跑通至少一个完整迭代
- 关键技术决策已有 ADR 沉淀

## 维护规则

- 每个版本开始前先更新本文件，明确本次迭代目标和非目标。
- 如路线调整涉及长期方向变化，需要同步更新 `vision.md`。
- 如版本推进依赖关键技术策略变化，需要新增或更新 ADR。

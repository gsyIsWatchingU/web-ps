# Web 修图项目产品愿景

## 背景

项目服务于 AIGC 带货图文生成后的二次精修场景。用户先通过 AI 获取初稿，再进入 Web 工作台完成结构化修图，包括比例调整、图层整理、花字包装、基础滤镜和导出，以满足投放、上新和运营场景的快速产出需求。

## 目标

- 打造一个面向桌面浏览器的轻量高频修图工作台。
- 聚焦带货图二次精修，不追求 Photoshop 级全能编辑。
- 让运营、设计和投手在同一个工具里完成从 AIGC 初稿到可投放素材的最后一公里。

## 目标用户

- 电商运营：需要快速修改标题字、卖点标签、尺寸比例和导出。
- 设计支持：需要基于 AI 初稿做花字包装、层级整理和细节调整。
- 投放人员：需要批量产出不同尺寸的投放素材，并确保主视觉和安全区稳定。

## 核心场景

1. 用户导入 AIGC 生成的商品图或图文海报。
2. 用户根据投放渠道切换比例和安全区。
3. 用户调整主图、文字、装饰元素和层级关系。
4. 用户应用基础滤镜和风格化花字。
5. 用户撤销/重做、保存草稿并导出最终素材。

## 阶段边界

### MVP

- 支持画布比例切换
- 支持图片导入与基础变换
- 支持图层管理
- 支持花字样式系统
- 支持基础滤镜
- 支持撤销重做
- 支持本地草稿恢复
- 支持 PNG/JPEG 导出

### 后续阶段

- AI 局部精修、智能消除、扩图
- 模板库与批量套版
- 多尺寸批量导出
- 协同审阅与权限控制

## 非目标

- 不在首版支持像素级专业修复工作流。
- 不在首版支持多人实时协同。
- 不在首版对接复杂工作流引擎或任务系统。

## 成功标准

- 用户能在一个工作台内完成 AIGC 初稿的主要二次精修。
- 首版高频链路稳定可用：导入 -> 编辑 -> 撤销/重做 -> 保存草稿 -> 导出。
- 文档、设计和任务分解以 SDD 方式持续积累，可支撑后续迭代扩展。

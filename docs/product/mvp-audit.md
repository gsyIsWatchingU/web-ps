# MVP 审计

## 说明

本文件用于回答一个具体问题：**按照“推荐 MVP 必做功能”来衡量，当前仓库是否已经做完？**

结论先行：**没有全部完成。**

当前仓库已经从“原型骨架”推进到了“可运行的轻量精修工作台”，并补齐了画布平移、裁剪、花字模板、电商滤镜模板和一键增强。距离推荐 MVP 仍差的关键能力主要集中在涂抹 / 橡皮擦 / 局部重绘、智能扩图和图文流程回填。

## 模块级判断

### 已基本达标

- 图层管理
- 基础花字编辑
- 基础滤镜调节
- 撤销 / 重做
- 草稿恢复
- PNG/JPEG 导出

### 部分达标

- 比例模块
  - 固定比例、安全区和自由裁剪完成
  - 智能扩图未完成
- 导出模块
  - 文件导出、版本命名和草稿恢复已完成
  - 图文流程回填仍未完成

### 未达标

- 涂抹与局部调整
- 图文流程回填

## 建议优先级

如果目标是尽快把“推荐 MVP 必做”收口，建议按以下顺序推进：

1. 笔刷 / 橡皮擦 / 局部重绘
2. 智能扩图
3. 图文流程回填
4. 前后对比与主体保护

## 与当前 Spec 的关系

当前仓库内的 `Editor MVP Spec` 实际定义的是一个**更收敛的 MVP**，重点覆盖比例切换、图层、基础花字、基础滤镜、撤销、草稿和导出，不包含涂抹、智能扩图和流程回填。

因此：

- 按“仓库当前 Spec”判断：大部分核心能力已经落地，但裁剪和正式验收仍未收口。
- 按“推荐 MVP 必做功能”判断：**尚未完成。**

# MVP 审计

## 说明

本文件用于回答一个具体问题：**按照“推荐 MVP 必做功能”来衡量，当前仓库是否已经做完？**

结论先行：**没有全部完成。**

当前仓库已经从“原型骨架”推进到了“可运行的轻量精修工作台”，但距离推荐 MVP 还差几块关键能力，尤其是涂抹、裁剪、画布平移、电商滤镜模板和图文流程回填。

## 审计结论

| 模块 | 推荐 MVP 必做 | 结果 | 说明 |
| --- | --- | --- | --- |
| 画布 | 图片加载 | `已完成` | 支持本地上传并生成图片图层 |
| 画布 | 缩放 | `已完成` | 支持预览缩放 |
| 画布 | 拖拽 | `未完成` | 画布平移未实现，仅对象拖拽已支持 |
| 画布 | 撤销重做 | `已完成` | 已接入历史栈和快捷键 |
| 涂抹 | 笔刷 | `未完成` | 无 brush 工具 |
| 涂抹 | 橡皮擦 | `未完成` | 无 eraser 工具 |
| 涂抹 | 局部重绘 | `未完成` | 无 AI 局部重绘链路 |
| 文字 | 添加文字 | `已完成` | 可新增文字层并编辑内容 |
| 文字 | 基础花字模板 | `未完成` | 只有样式调节，无模板库 |
| 文字 | 描边阴影 | `已完成` | 描边、阴影、渐变、背景条都已支持 |

| 导出 | 回填到图文流程 | `未完成` | 未对接外部流程或回填入口 |

## 模块级判断

### 已基本达标

- 图层管理
- 基础花字编辑
- 基础滤镜调节
- 撤销 / 重做
- 草稿恢复
- PNG/JPEG 导出

### 部分达标

- 画布模块
  - 图片加载和缩放完成
  - 画布平移未完成
- 比例模块
  - 固定比例和安全区完成
  - 自由裁剪和智能扩图未完成
- 文字模块
  - 样式调节完成
  - 模板化能力未完成

### 未达标

- 涂抹与局部修复
- 电商滤镜模板与一键增强
- 图文流程回填

## 建议优先级

如果目标是尽快把“推荐 MVP 必做”收口，建议按以下顺序推进：

1. 画布拖拽平移
2. 自由裁剪
3. 笔刷 / 橡皮擦 / 局部重绘
4. 电商滤镜模板与一键增强
5. 基础花字模板
6. 图文流程回填

## 与当前 Spec 的关系

当前仓库内的 `Editor MVP Spec` 实际定义的是一个**更收敛的 MVP**，重点覆盖比例切换、图层、基础花字、基础滤镜、撤销、草稿和导出，不包含涂抹、智能扩图和流程回填。

因此：

- 按“仓库当前 Spec”判断：大部分核心能力已经落地，但裁剪和正式验收仍未收口。
- 按“推荐 MVP 必做功能”判断：**尚未完成。**
